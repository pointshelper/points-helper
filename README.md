# Points Helper for Aeroplan

A Chrome extension that checks your Aeroplan eStore points will track at Amazon.ca and Walmart.ca, and flags items that won't earn before you buy.

### [➜ Install from the Chrome Web Store](https://chromewebstore.google.com/detail/ekngfhnjmlapahlimppmandopdncagbg)

Free. Works in Chrome, Edge, Brave and Arc. It's an unlisted beta, so this link is the only way to find it.

**[What's next](https://pointshelper.github.io/points-helper/)**: requests and what's being worked on.

## Report a bug or ask for a store

[Open an issue](https://github.com/pointshelper/points-helper/issues/new/choose) and pick a template:

- **Bug report**: something didn't work or looked wrong.
- **Store request**: an eStore retailer you'd like supported.
- **Idea**: anything else that would make it better.

Already requested? Add a 👍 to the issue instead of opening a new one.

No GitHub account? Email **pointshelper.support@gmail.com** or use the Feedback button in the extension.

**Please don't post order numbers, addresses or screenshots with personal details.** Issues are public.

## Privacy

- It only runs on the stores it supports. Chrome doesn't let it see any other site.
- Everything it saves (activation times, your order log) stays in your browser.
- It sends nothing anywhere: no accounts, no analytics, no servers.
- It never changes links or tracking. It only reads them to tell you whether points will track.

## The code

The [`extension`](extension) folder has the code for the version on the Chrome Web Store (0.1.1), so you can check what it does. It's shared for transparency, not as open source.
